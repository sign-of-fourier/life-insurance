# Phase 1.1 survey notes (structure only; no text copied)

Sources skimmed 2026-11-09: carrier field guides / preferred criteria (Equitable, Lincoln,
Securian, Protective, Pacific Life, PRCUA), brokerage generic criteria chart, SOA preferred-
criteria experience studies, SOA Transactions papers on the numerical rating system, RGA GUM
brochure (manual itself is registration-only).

Common structure we adopt:
- Preferred classes defined by a criteria matrix (build, BP, lipids, tobacco lookback, family
  history, MVR, avocation/aviation, personal medical history) with age-banded thresholds;
  Securian-style tiers (best class / preferred / non-tobacco plus) map to our Elite/PP/P/SP.
- Build chart by height with max weight per class (examples ~5'0" PP max ~161 lb).
- Typical PP-type limits seen: BP < 140/90 treated, TC < 275, TC/HDL < 5.5 (we tier tighter).
- Family history often disregarded at older ages (e.g. 70+).
- Credits programs (Securian mortality credits, Protective "Pro Credit") offset debits for
  favorable factors, usually only toward Standard; we cap credits and bar preferred uplift.
- Numerical rating: debits ~= % extra mortality; tables of +25% each; flat extras for
  aviation/avocation/occupation/residence & travel; aviation exclusion vs. rating options.
- Requirements by age/amount grid; accelerated (no-fluid) path for young/low amounts.
Real debit values are not public -> all numbers in guidelines.md are invented but internally
consistent.
